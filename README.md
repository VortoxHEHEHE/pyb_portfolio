## 🚀 À propos du projet

Ce portfolio a été conçu pour présenter mon identité numérique professionnelle. Il est entièrement responsive (adapté aux mobiles et PC) et respecte les standards du web actuel.

### Objectifs du site :
- Présenter mon profil et mon CV.
- Détailler mon parcours académique (**Paris YNOV Campus**) et professionnel.
- Mettre à disposition mes documentations techniques pour les épreuves **E5 (Missions)** et **E6 (Projets)**.
- Partager ma veille technologique.

---

## 🛠️ Stack Technique

Ce site est réalisé "from scratch" (sans constructeur de site comme WordPress ou Wix) pour démontrer ma capacité à comprendre et modifier le code source.

* **Langages :** HTML5, CSS3, JavaScript (Vanilla).
* **Hébergement :** GitHub Pages.
* **Nom de domaine :** Configuré via OVH avec sécurisation SSL (HTTPS).
* **Polices :** Inter et Space Mono (Google Fonts) hébergées localement dans `/assets/fonts/`, pour la performance et le respect du RGPD (aucune requête vers Google).
* **Formulaire de contact :** Géré via l'API Formspree.

---

## 📂 Structure du site

L'architecture du projet est organisée comme suit :

* `/` : Page d'accueil (`index.html`).
* `/pages/` : Contient toutes les sous-pages (À propos, BTS SIO, Missions, Veille...).
* `/style/` : Feuilles de style CSS (Design global, responsive, polices).
* `/script/` : Scripts JavaScript pour les interactions (Menu mobile, animations).
* `/assets/` : Images, logos et documents PDF (Rapports de projets).
